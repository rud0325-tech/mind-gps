# MindGPS 캐릭터

사용자가 제공한 `MindGPS_캐릭터_최종9명.svg`에서 앱용으로 분리한 9개 SVG입니다.
원본 시트는 수정하지 않았으며, 원래의 지도 핀 모양·색상·표정을 유지했습니다.

- 순서: 무대스타 → 크리에이터 → 토닥이 → 게임히어로 → 음악메이트 → 스포츠에이스 → 그림작가 → AI공학자 → 동물지킴이
- 각 파일은 투명 배경, `280 × 280`, 공통 `viewBox="-10 -10 280 280"`입니다.
- 작은 화면에서도 대표 소품을 알아볼 수 있도록 부유 장식을 줄였습니다.
- 크리에이터는 휴대폰, 스포츠에이스는 농구공과 머리띠를 중심으로 정리했습니다.
- 토닥이는 의료 소품을 빼고 두 팔로 하트를 안는 모습으로 바꾸었습니다.
- 카드 테두리·이름표·시트 제목은 앱 화면에서 따로 표시합니다.
- 외부 이미지·스크립트·외부 참조를 포함하지 않습니다.

원본에서 다시 생성하려면 저장소 루트에서 다음을 실행합니다.

```sh
python3 scripts/extract-character-assets.py /path/to/MindGPS_캐릭터_최종9명.svg
```

이는 사용자 제공 자료를 앱에 맞게 편집한 파일이며 별도의 외부 캐릭터 라이선스를 주장하지 않습니다.
