# 생각 바꾸기 문장별 타입캐스트 음성

이 폴더는 완성한 MP3를 넣는 위치입니다. 대본과 파일명 목록만 준비했으며, 문장별 음성 파일이 이미 만들어진 것은 아닙니다. 빈 MP3나 임시 소리를 넣지 않습니다.

- 같은 목소리: 기존 MindGPS 음성을 제작한 타입캐스트 캐릭터와 말투·감정·속도 설정을 확인하고 사용합니다.
- 제작할 때는 통합 대본 순서대로 문장 사이에 약 2초의 무음을 넣어 하나의 MP3로 만들 수 있습니다. 배경음악·효과음은 넣지 않습니다.
- 앱에 연결할 때는 완성한 파일의 문장 경계를 확인하여 문장 하나당 MP3 하나로 분리합니다.
- 파일명: `src/learning/rebtVoiceLines.ts`의 `fileName`과 정확히 맞춥니다. 예: `prompt-situation.mp3`, `v24-greeting-situation.mp3`, `v26-study-helpful.mp3`.
- 같은 문장: 똑같은 문장은 첫 항목의 파일 하나를 함께 사용합니다. 화면이나 학습 수준별로 같은 문장을 중복 제작하지 않습니다.
- 현재 25개 상황: 이전 문장을 유지한 상황은 `v24-`, 이번에 수정하거나 추가한 상황은 `v25-`로 시작하는 파일명을 사용합니다. 이전 대본에서 문장이 달라진 경우, 이전 녹음의 이름만 바꾸어 연결하지 않습니다.
- 직접 등록한 새 문장: 고정 대본에 들어 있지 않습니다. 글을 등록하는 것만으로 같은 타입캐스트 목소리가 생성되지는 않습니다.
- 기존 `guide_rebt.mp3`: 활동 전체 안내이므로 새로운 문장별 대본을 대신할 수 없습니다.
- 현재 임시 듣기: 문장별 MP3가 없는 경우 화면에서 선택한 정확한 문장을 기기 기본 음성으로 읽습니다. 그림을 누르면 선택과 함께 읽으며, 단계 이동·게임 방식 전환·화면 종료 시 멈춥니다. 지정한 MP3를 넣고 다시 빌드하면 해당 문장부터 타입캐스트 녹음을 우선 사용합니다.
- ‘오늘의 한마디’에서는 선택한 바꾼 생각만 읽습니다. 칭찬 음성과 이미지 저장은 활동 후 감정 기록을 마친 다음 완료 화면에서 제공합니다.
- 적용 확인: 파일을 넣고 앱을 다시 빌드한 다음, 화면 문장과 실제 읽는 내용이 맞는지 확인합니다.

대본 갱신:

```sh
node --import tsx scripts/export-rebt-voice-script.ts
```

기본으로 작업 폴더의 `outputs`에 통합 TXT 대본, Markdown과 UTF-8 BOM CSV를 만듭니다. 다른 출력 폴더를 지정하려면 마지막 인자로 폴더 경로를 넣습니다. 대본은 기본 학습 문장만 읽으며 직접 등록한 학생의 문장이나 활동 기록은 포함하지 않습니다.
