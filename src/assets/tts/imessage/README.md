# 나전달법 완성 문장 타입캐스트 음성

학생이 선택한 상황·마음·부탁을 자연스럽게 이어 읽는 MP3를 넣는 폴더입니다. 현재는 36개 완성 문장의 대본과 파일명 목록을 준비한 상태이며, 새 녹음이 이미 제공된 것은 아닙니다. 빈 MP3나 임시 음성을 넣지 않습니다.

현재 앱은 사용자가 허용한 기기 기본 음성으로 완성 문장을 읽고 ‘기기 음성’이라고 표시합니다. 아래 파일명에 맞는 MP3가 추가되면 그 문장은 녹음을 우선 사용하며 ‘타입캐스트’로 표시합니다. 파일을 추가한 뒤 다시 빌드해야 합니다.

- 기존 MindGPS 타입캐스트 프로젝트의 목소리·말투·감정·속도를 확인해 사용합니다.
- `MindGPS_나전달법_통합음성대본_20261007_v6.txt`를 순서대로 읽고, 빈 줄로 나뉜 각 문단 사이에 약 2초의 무음을 넣어 하나의 MP3로 만들어도 됩니다. 문단 안의 상황·마음 문장과 부탁 문장은 자연스럽게 이어 읽습니다.
- 완성 파일을 확인하며 문단 하나당 MP3 하나로 나누어 연결합니다. 배경음악·효과음은 넣지 않습니다.
- 파일명은 `src/learning/iMessageVoiceLines.ts`의 `fileName`과 정확히 맞춥니다. 예: `imessage-noise-uncomfortable-quieter.mp3`.
- 현재 상황 순서는 친구의 놀리는 말, 어려운 활동, 큰 목소리, 지금 할 수 없는 활동입니다. 마지막 상황의 새 파일명은 `activity-unavailable`을 사용하며 이전 `waiting` 녹음을 재사용하지 않습니다.
- 기존 `guide_i_message.mp3`는 전체 활동 안내이며, 학생이 선택한 완성 문장의 낭독을 대신하지 않습니다.
- 단어·부정·조사 등이 달라진 문장을 비슷한 녹음에 연결하지 않습니다. 문장을 수정하면 대본과 녹음도 함께 갱신합니다.
- 파일을 넣고 앱을 다시 빌드한 뒤, 모든 조합의 화면 문장과 실제 읽는 내용이 맞는지 확인합니다.

대본 갱신:

```sh
node --import tsx scripts/export-imessage-voice-script.ts
```

기본 출력 위치는 작업 폴더의 `outputs`이며, 문장만 담은 TXT와 파일명 대조용 Markdown·UTF-8 BOM CSV를 만듭니다. 마지막 인자로 다른 출력 폴더를 지정할 수도 있습니다. 앱의 고정 학습 문장만 사용하고 학생 이름이나 활동 기록은 읽지 않습니다.
