# 음성 입력 확인 안내

생각 바꾸기와 나전달법의 음성 입력은 브라우저의 한국어 음성 인식 기능을 사용합니다. 앱이 마이크 장치를 고르거나 iPhone에 연결하는 코드는 없습니다. 기기·브라우저가 선택한 마이크와 음성 인식 서비스가 모두 작동해야 글이 입력됩니다.

## iPhone에 ‘Mac에 연결됨’이 나타날 때

iPhone을 Mac의 마이크로 사용하는 **연속성 카메라** 기능일 수 있습니다. 이 알림만으로 소리가 휴대폰 스피커로 재생된다고 판단할 수는 없습니다. 입력과 출력을 따로 확인합니다.

1. Mac의 **시스템 설정 → 사운드 → 입력**에서 MacBook의 내장 마이크를 선택합니다. 브라우저에 별도 마이크 선택이 있으면 그곳도 확인합니다.
2. 실제 소리가 다른 기기에서 나올 때는 **사운드 → 출력**에서 MacBook 스피커를 확인합니다.
3. iPhone을 Mac의 카메라·마이크로 전혀 사용하지 않으려면 iPhone의 **설정 → 일반 → AirPlay 및 연속성**에서 **연속성 카메라**를 끌 수 있습니다. OS 버전에 따라 메뉴 이름이 조금 다릅니다. 이 설정을 끄면 다른 앱에서도 해당 기능을 사용할 수 없습니다.

기기 선택은 사용자가 확인하고 변경합니다. 앱은 이 설정을 임의로 바꾸지 않습니다. 자세한 경로는 [Apple의 연속성 카메라 안내](https://support.apple.com/ko-kr/102546), [사운드 입력 안내](https://support.apple.com/ko-kr/guide/mac-help/mchlp2567/mac), [사운드 출력 안내](https://support.apple.com/ko-kr/guide/mac-help/mchlp2256/mac)를 참고합니다.

## 오류 문구에 따른 확인

| 앱에서 보이는 내용 | 뜻과 다음 확인 |
| --- | --- |
| 음성 인식 서비스에 연결하지 못했어요 | 인식에 필요한 서비스 통신이 실패했습니다. 전체 인터넷이 끊겼다는 뜻은 아닙니다. 인터넷 연결을 확인하고, 같은 주소를 다른 지원 브라우저에서 열어 비교합니다. |
| 이 브라우저의 음성 인식 서비스를 사용할 수 없어요 | 해당 서비스가 브라우저에서 지원되지 않거나 허용되지 않았습니다. 마이크 권한만 다시 주어도 해결되지 않을 수 있습니다. 다른 브라우저 또는 직접 입력을 사용합니다. |
| 마이크 사용이 허용되지 않았어요 | 기기와 브라우저의 마이크 권한을 확인합니다. |
| 마이크 소리를 받지 못했어요 | 사용 중인 입력 장치, 연결 상태, 다른 앱의 마이크 사용을 확인합니다. |
| 음성 입력이 준비되기 전에 연결이 끝났어요 | 인식 준비가 완료되기 전에 서비스가 종료됐습니다. 선택된 마이크와 연결 상태를 확인합니다. 말하지 않아서 생긴 오류로 단정하지 않습니다. |
| 음성 입력이 끝났지만 인식된 말이 없어요 | 소리 입력은 끝났으나 결과를 받지 못했습니다. 사용 중인 마이크와 연결 상태를 확인하거나 직접 입력합니다. 이 문구만으로 기기 연결 해제를 확정하지 않습니다. |
| 음성 입력을 준비하지 못했어요 | 20초 동안 인식 준비가 끝나지 않았습니다. 마이크 선택, 연결 상태, 브라우저 권한을 함께 확인합니다. |
| 말소리를 듣지 못했어요 | ‘듣고 있어요’ 표시 후 짧은 문장으로 다시 말합니다. |

브라우저마다 음성 인식 지원과 처리 방식이 다릅니다. 일부 브라우저는 서버에서 인식하므로, 마이크가 정상이어도 서비스 연결 문제로 실패할 수 있습니다. 새 외부 인식 서비스나 API를 연결하지 않아도 브라우저를 바꿔 비교할 수 있지만, 특정 브라우저에서의 성공을 보장하지는 않습니다. [MDN 음성 인식 설명](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [오류 종류](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognitionErrorEvent/error).

## 앱에서 보완한 부분과 확인 범위

- 인식 중인 글을 별도 아래 상자 대신 실제 입력칸에 표시해, 듣고 있는 내용을 바로 볼 수 있도록 했습니다. 중간 글은 인식 과정에서 바뀔 수 있습니다.
- ‘말하기 마치기’를 누른 뒤 늦게 도착하는 최종 결과를 기다립니다. 최종 결과 없이 끝나면 들은 임시 문장을 남기고 수정할 수 있게 합니다.
- 브라우저가 소리 입력 종료를 알리면 ‘듣고 있어요’를 멈추고 결과를 최대 5초 기다립니다. 생각 바꾸기에는 ‘마지막 말을 정리하고 있어요. 잠시만 기다려 주세요.’, 나전달법에는 ‘마지막 말을 확인하고 있어요.’가 표시됩니다. 입력 종료는 정상 처리 과정에서도 발생하므로 즉시 기기 연결 오류로 판단하지 않습니다. 종료 알림이 더 오지 않아도 기다리는 시간이 끝나면 입력칸을 다시 사용할 수 있습니다.
- 서비스 연결 실패, 서비스 사용 불가, 마이크 권한·장치 오류를 구분해 안내합니다. 오류가 나도 이미 받은 글은 보존합니다.
- 원본 음성은 앱에서 녹음 파일로 만들거나 저장하지 않습니다. 브라우저의 외부 서비스에서 음성을 처리할 수 있습니다. 등록할 글은 확인한 뒤 저장합니다.

자동 검증은 인식 이벤트·오류·중단 상황을 모의하여 글 보존과 상태 처리를 확인했습니다. 소리 입력 종료 후 늦은 최종 결과, 결과·종료 알림 누락, 준비 전 종료, 취소 후 늦은 알림도 포함합니다. 실제 마이크를 켜거나 학생 음성을 전송하지 않았으므로, 실제 발음 인식률이나 특정 기기의 서비스 연결 해결까지 확인한 것은 아닙니다.
