# 생각 바꾸기와 나-전달법의 학습 내용

## 공통 기준

- 문장·그림과 단어·그림 모드는 같은 상황과 선택지를 사용한다.
- `word`는 카드에 표시하는 짧은 말이고, `sentence`는 완전한 설명이나 발화이다. 짧은 말을 문장 틀에 억지로 끼우지 않는다.
- 생각바꾸기 그림 모드는 구체적인 상황·생각 장면을 보여 주며, 그림을 누르면 해당 문장을 읽는다. 기본 상황은 이야기 속 친구의 생각 한 장을 보고, 함께 살펴보기와 친구에게 도움 되는 생각 한 장으로 이어진다. 음성에서도 등장인물의 이야기임을 먼저 알린다. 처음 생각에는 선택 체크나 정답 표시가 없다. 그림과 단어 모드는 그림에 핵심어를 함께 표시한다.
- 정확한 문장의 타입캐스트 녹음이 있으면 우선 사용하고, 없는 문장은 기기 기본 음성으로 임시 재생한다. 학생이 눌러야 시작되며 단계 이동·화면 이탈 시 멈춘다. 기기 음성의 가용성과 품질은 실제 수업 기기에서 확인한다.
- 학습 내용은 가상 연습이다. 학생에게 실제로 일어난 사건이나 학습 효과를 기록했다고 해석하지 않는다. 상대의 반응을 예측하거나 성공을 보장하지 않는다.
- 도움받기 선택지는 말하기 연습이며 실제 알림을 보내는 버튼과 구분한다. 실제 도움이 필요한 경우 전역 도움 요청 버튼을 이용하거나 가까운 선생님께 알리도록 안내한다.
- ‘연습을 마쳤어요’는 학습 종료이다. 감정이 좋아졌거나 독립적으로 수행했음을 의미하지 않는다.

## 생각 바꾸기

상황 → 떠오른 생각 → 진짜 그럴까? → 도움 되는 생각 한 장 함께 보기 → 바꾼 생각 정리 → 활동 후 감정 → 칭찬 카드.

2026년 10월 7일 검토한 25개 상황을 다음과 같이 묶는다. ‘처음 연습’은 앱의 활동 흐름을 익힐 수 있도록 대표 사례를 모은 목록이며, 특정 학생에게 빈번한 신념으로 진단한 목록이 아니다. 기본 목록은 친구와 다툼·활동 어려움·게임에서 짐·하고 싶은 활동을 지금 할 수 없음의 네 상황이다. 기존 인사·문제 틀림·시간표 변경은 각각 친구 관계·수업과 공부·변화와 일과에서 계속 이용할 수 있다.

| 묶음 | 수 | 상황 |
| --- | ---: | --- |
| 친구 관계 | 5 | 인사에 대답 없음, 친구들끼리 웃는 대화, 짝꿍의 다른 친구, 부탁 거절, 친구와 다툼 |
| 수업과 공부 | 5 | 문제 틀림, 활동 어려움, 발표에 대한 걱정, 늦게 마친 활동, 발표할 때 친구들의 시선 |
| 실수와 실패 | 4 | 실수로 친구와 부딪힘, 선생님께 큰 소리로 말함, 실습 실수, 시합·게임에서 짐 |
| 선생님과 규칙 | 3 | 선생님의 지적, 하고 싶은 활동 제한, 나만 혼난 상황 |
| 비교와 평가 | 3 | 친구의 칭찬, 친구와 비교, 상을 받지 못함 |
| 놀림과 외모 | 2 | 외모 놀림, 싫은 별명 |
| 변화와 일과 | 3 | 갑작스러운 시간표 변경, 좋아하는 활동 취소, 처음 가는 장소 |

기본 ‘알아보기’는 ‘이야기로 연습해요 → 친구의 생각을 들어 봐요 → 함께 살펴봐요 → 친구에게 도움 되는 생각 → 오늘 연습한 생각’으로 진행한다. 모든 단계에 ‘이야기 속 친구’를 표시하고, 처음 생각은 등장인물의 말풍선으로 제시한다. 학생이 상황을 골랐다는 이유로 그 생각에 동의하거나 실제로 그렇게 생각한다고 추정하지 않는다. 상황·생각·함께 살펴보기·도움 생각의 음성도 이야기 속 친구의 내용임을 알린다. 학생이 고른 아바타의 생각이라고 표현하지 않는다.

‘내 이야기’는 별도로 직접 입력한 내용만 사용한다. 상황 선택 화면의 버튼과 이야기의 생각 화면에서 연결되며, 기본 이야기 연습을 위해 자기 생각을 말하거나 입력할 필요는 없다. 기존 등록 내용을 보존하고 사용자 문장을 자동으로 비합리적이라고 분류하지 않는다. 기록에는 기본 활동을 ‘이야기로 연습’, ‘이야기 속 친구의 생각’, ‘오늘 연습한 생각’으로 표시한다. 내 이야기는 일반적인 완료 사실만 요약하며, 직접 입력한 문장은 외부 기록에 넣지 않는다. 도움 되는 생각은 승인된 문장을 사용하고, 타인의 의도나 다음 기회·승리·도움의 결과를 보장하지 않는다.

미로 게임은 기본 상황 중 하나를 무작위로 제시하고, 화살표 키나 화면 방향 버튼으로 이동한다. 상황에 맞는 도움 되는 생각의 길을 지나 도착한다. 힘든 생각의 길에서는 목숨이나 점수를 잃지 않고 다시 살펴보도록 안내한다. 직접 등록한 상황은 무작위 게임에서 제외한다. 게임의 성공은 연습을 마친 뜻이며 실제 감정 개선이나 행동 변화를 입증하지 않는다.

바꾼 생각 정리는 도움 되는 생각을 말하거나 들어 보며 다시 살펴보는 단계이다. 이 단계에 칭찬 듣기와 카드 저장을 두지 않는다. 활동 후 감정 기록을 거쳐 완료 화면에서 칭찬과 카드 저장을 제공한다. 어려운 활동·친구 다툼·실수·놀림 상황에는 필요할 때 사용할 표현 두 개를 각각 들을 수 있게 한다. 친구 다툼은 진정 뒤 마음을 표현하거나 대화 도움을 요청하는 전략이며, 화해나 용서를 보장하지 않는다. 놀림에서 싫다고 먼저 말하거나 반복될 때까지 기다려야 교사에게 도움을 요청할 수 있는 구조로 만들지 않는다. 이 표현 듣기는 실제 교사 알림 전송이 아니다.

직접 등록한 상황은 새로 만들 때 도움 되는 생각 한 장을 저장한다. 이전에 등록한 두 번째 도움 카드·추가 생각·행동·그림 종류는 불러오거나 첫 문장을 고칠 때 보존한다. 이전 묶음 이름은 새 묶음으로 해석하며, 읽기만으로 기존 저장 내용을 덮어쓰지 않는다. 직접 등록한 글은 외부 전송용 활동 요약이나 음성 제작 대본에 넣지 않는다.

급식판 상황은 친구와 부딪힌 상황, 선생님께 화가 나서 큰 소리로 말한 상황으로 나누어 교체했다. 행동을 돌아보며 사과하거나 도움을 요청하는 연습과 학생 자신을 나쁜 사람으로 평가하는 생각을 구분한다. 사과한 뒤 상대가 반드시 용서하거나 특정하게 반응할 것이라고 약속하지 않는다. 어려운 수업은 설명을 다시 부탁하거나 스스로 천천히 다시 생각해 보는 표현을 제공한다. 활동 제한은 이유를 물어보고 가능한 때나 방법을 알아보도록 하며 제한이 언제나 정당하다고 가정하지 않는다.

문장 개정에 따라 `v24-`, `v25-`, `v26-` 식별자를 사용하며, 이번 활동 어려움·친구 다툼·활동 제한은 `v26-`을 쓴다. 문장이 바뀐 이전 녹음을 새 문장에 잘못 연결하지 않도록 문장별 음성 파일명도 갱신한다. 이전에 직접 등록한 급식판 그림 등은 저장 호환을 위해 유지한다. 대본·파일명 목록이 준비되었다고 실제 타입캐스트 녹음이 제작된 것은 아니다.

## 나-전달법

상황 → 감정 → 상황별 부탁 → 완성 문장 → 표현했어요 → 활동 후 감정 → 칭찬 카드.

| 상황 | 부탁 |
| --- | --- |
| 주변 사람의 큰 목소리 | 목소리를 낮춰 달라고 요청 / 조용한 곳에서 쉬도록 도움 요청 |
| 긴 기다림 | 기다릴 시간 확인 / 기다리는 동안 잠깐 쉬겠다고 표현하기 |
| 친구가 나를 놀리는 말을 함 | 그런 말은 하지 말아 줘 / 나한테 다정하게 말해 줘 |
| 지금 하는 활동이 어려움 | 한 번 더 알려 달라고 요청 / 조금 더 쉬운 활동 요청 |

완성 문장 예: “네가 나를 놀리는 말을 하면 나는 속상해. 그런 말은 하지 말아 줘.” 친구 상황의 학생 발화는 반말로 구성하고, 화면의 안내·질문과 다른 상황의 발화는 존댓말을 유지한다.

완성 문장의 글 보기에는 ‘1 상황 / 2 내 마음 / 3 부탁’을 붙여 세 부분을 구분한다. 문장 수준과 다른 수준의 ‘문장으로 보기’에 같은 구성을 사용한다. 옅은 배경색과 글자 이름을 함께 사용하며, ‘완성 문장 듣기’는 세 부분의 실제 문장을 끊어진 별도 음성이 아닌 하나의 발화로 이어 읽는다. 구분을 위한 이름과 번호는 발화에 넣지 않는다.

학습 상황 예: “지금 하는 활동이 어려우면 저는 걱정이 돼요. 한 번 더 알려 주세요.” 또는 “지금 하는 활동이 어려우면 저는 걱정이 돼요. 조금 더 쉬운 걸로 해 볼래요.” 그림은 문제풀이 학습지 대신 모양 맞추기 활동을 사용하며, 설명을 다시 듣는 모습과 같은 종류의 더 간단한 활동을 구분해 보여 준다.

마지막 ‘표현했어요’는 말하기뿐 아니라 그림을 가리키거나 문장을 보여 주는 표현도 포함한다. 기다리기에서는 ‘얼마나 더 기다려야 하는지 알려 주세요.’와 ‘기다리는 동안 잠깐 쉴래요.’ 중에서 고른다. 그림 수준에는 시간 확인 장면과 시계 옆 빈백에서 쉬는 장면을 제시한다. 상대의 반응을 예측하는 단계는 두지 않으며, 요청이 반드시 받아들여진다고 약속하지 않는다.

## 구성과 검증

- 나-전달법 내용: `src/learning/content.ts`
- 생각바꾸기 내용·게임: `src/learning/simpleRebt.ts`, `src/learning/rebtPathGame.ts`
- 직접 등록한 생각바꾸기 내용 보존: `src/lib/rebtLibrary.ts`
- 활동 화면: `src/components/LearningActivity.tsx`, `src/components/RebtActivity.tsx`
- 문장별 음성 목록: `src/learning/rebtVoiceLines.ts`
- 콘텐츠 점검: `node --import tsx --test src/learning/content.test.ts src/learning/simpleRebt.test.ts src/learning/rebtVoiceLines.test.ts tests/rebtLibrary.test.ts`
- 타입 점검: `npm run lint`

콘텐츠 점검은 상황별 선택지 연결, 미해결 결과와 도움 경로, 모든 감정·부탁 조합의 문장 생성, 연습 기록과 효과 측정의 구분을 확인한다. 실제 학생의 이해도, 상징 적합성, 목소리 품질, 교육적 효과는 수업 적용과 교사 검토가 필요하다.


### 2026-10-07 나-전달법과 파워카드

- 기본 상황은 친구의 놀리는 말 → 어려운 활동 → 주변의 큰 목소리 → 하고 싶은 활동을 지금 할 수 없음 순서다. 각 상황은 고유 ID로 마음·부탁·완성 문장에 연결한다.
- 마지막 상황의 부탁은 이유 알려주기, 가능한 때 묻기, 다른 활동 고르기다. 이전 기다리기 상황의 사용자 추가 내용은 보존하며 새 상황에 자동 연결하지 않는다.
- 파워카드의 공통 요소는 선택한 웃는 캐릭터, 연습한 상황/사용할 맥락, 실제로 고르거나 연습한 해결 방법이다. 나-전달법은 선택한 마음과 부탁으로 만든 문장, 생각 바꾸기는 도움이 되는 생각, 이완훈련은 실시 표시한 동작, 마음의 소리는 실제 재생에 성공한 소리를 담는다.
- REBT 예시 상황에는 ‘이야기 속 상황’을 표시해 학생의 실제 경험으로 단정하지 않는다. 어려운 생각이나 감정 점수는 카드에 복사하지 않는다.
- 카드 원문은 화면과 PNG에서 같은 구조로 표시한다. 그림·단어 모드에도 해결 방법의 핵심 행동을 생략하지 않고, 내용 듣기는 완전한 문장을 읽는다. 정확히 일치하는 나-전달법 타입캐스트 파일이 있으면 우선 사용하고 그 외에는 기기 음성으로 읽는다.
- 카드용 내용은 활동 완료 → 사후 기분 기록 → 칭찬 화면 사이의 로컬 상태로만 전달하며 교사 저장 기록에 필드를 추가하지 않는다. 새 활동/새 시작 때 초기화한다.

### 칭찬 파워카드 앞·뒷면

- 칭찬 화면에 도착하면 앞면(선택한 웃는 캐릭터와 짧은 칭찬)을 먼저 보여 준다. 카드 어느 곳이든 누르거나 키보드 Enter/Space로 뒤집을 수 있다. 동작 줄이기 설정에서는 회전 애니메이션을 생략한다.
- 뒷면은 캐릭터와 학습 맥락·해결 방법을 담는다. 나-전달법은 명시적으로 전달된 상황/내 마음/부탁을 각 한 번씩 표시하고, 음성은 기존의 완성 문장을 읽는다. 다른 활동도 실제로 연습한 방법을 유지한다.
- 카드 뒤집기는 선택적인 복습이다. 활동 완료와 기록 저장은 카드 앞면이 나오기 전에 처리하며, 뒤집기 여부로 저장·종료·긍정 메시지 기능을 제한하지 않는다.
- 파워카드 이미지 저장은 현재 보는 면과 관계없이 앞면과 뒷면을 나란히 배치한 PNG 한 장을 만든다. 오늘의 긍정 메시지 이미지는 기존 한 면 구성을 유지한다.
