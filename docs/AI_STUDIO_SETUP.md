# 마음GPS 실제 운영판을 AI Studio 새 프로젝트로 여는 방법

이 판은 학생 기록을 Firebase에 실제로 저장합니다(`app-mode.json`의 `dataMode: live`). 기존 AI Studio 앱과 기존 데이터베이스는 건드리지 않도록, Firebase 연결 정보(`firebase-applet-config.json`)를 비워 두었습니다. 새 AI Studio 앱에서 Firebase를 연결하면 이 앱만의 새 데이터베이스가 만들어집니다.

연결하기 전에는 학생 화면 왼쪽 위에 빨간 **기록 저장 연결 필요**가 보이고, 기록은 저장되지 않습니다.

## 1. AI Studio에 새 앱으로 올리기

1. [Google AI Studio](https://aistudio.google.com)에서 **Build**를 엽니다.
2. 프롬프트 입력창의 **+** 버튼에서 zip 올리기를 고르고 `마음GPS-실제운영판.zip`을 올립니다. 메뉴 이름은 AI Studio가 바꿀 수 있습니다.
3. 에이전트가 자동으로 무언가를 만들기 시작하면 멈추고, 올린 파일이 그대로 들어왔는지 확인합니다(`app-mode.json`, `firestore.rules`, `src` 폴더).
4. 미리보기에서 첫 화면이 보이고 왼쪽 위에 **기록 저장 연결 필요**가 보이면 정상입니다.

zip 올리기가 보이지 않으면 GitHub에서 가져올 수도 있습니다. 이 판을 기본 브랜치로 둔 새 저장소를 만든 뒤 **+ → Import from GitHub**로 고릅니다(기존 저장소의 기본 브랜치는 예전 앱이라 쓰지 않습니다).

## 2. Firebase 연결하기

AI Studio 에이전트에게 아래 문장을 그대로 보냅니다.

```
이 앱은 Firebase 연결 코드와 보안 규칙이 이미 완성되어 있어.
Firebase(Firestore 데이터베이스와 Google 로그인)를 새로 연결해 줘.
firebase-applet-config.json에 새 연결 정보만 채우고,
지금 있는 firestore.rules를 내용 그대로 배포하고,
firestore.indexes.json에 있는 색인도 만들어 줘.
src 폴더의 코드, firestore.rules, firebase-blueprint.json, app-mode.json은 고치지 마.
로그인 화면이나 새 기능도 추가하지 마.
```

에이전트가 다른 파일을 고치겠다고 하면 거절합니다. 연결이 끝나면 `firebase-applet-config.json`에 값이 채워지고, 왼쪽 위의 빨간 표시가 사라집니다.

## 3. Firebase 콘솔에서 익명 로그인 켜기

학생 기록은 학생이 로그인하지 않아도 저장되도록 ‘익명 로그인’을 씁니다. AI Studio는 Google 로그인만 켜 주므로 이것은 직접 켭니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 AI Studio가 만든 프로젝트를 엽니다(‘AI Studio’ 표시가 있는 프로젝트).
2. 왼쪽 **보안(Security) → Authentication → 로그인 방법(Sign-in method)**에서 **익명(Anonymous)**을 사용 설정하고 저장합니다.

## 4. 앱에서 연결 점검하기

앱 첫 화면의 **선생님 → 연결 점검**을 누릅니다. 세 줄이 모두 ‘정상’이어야 합니다.

| 항목 | ‘확인 필요’일 때 |
|---|---|
| 기록 저장소 연결 정보 | 2단계를 다시 합니다. 여기 나온 데이터베이스 이름을 5단계에서 씁니다. |
| 학생 기록용 익명 로그인 | 3단계를 확인합니다. |
| 보안 규칙 | AI Studio 에이전트에게 “firestore.rules를 내용 그대로 다시 배포해 줘”라고 보냅니다. |

## 5. 나를 운영자로 승인하기

1. 앱에서 **선생님 → Google 계정으로 로그인**을 누릅니다. 처음에는 ‘승인이 아직 없어요’와 함께 **계정 번호**가 나옵니다. **계정 번호 복사**를 누릅니다.
2. Firebase 콘솔 왼쪽 **데이터베이스 및 스토리지(Databases & Storage) → Firestore**를 열고, 위쪽 데이터베이스 목록에서 4단계에 나온 데이터베이스를 고릅니다.
3. **컬렉션 시작** → 컬렉션 ID `teachers` → 문서 ID에 복사한 계정 번호를 붙여 넣습니다.
4. 필드 이름 `admin`, 유형 `boolean`, 값 `true`로 저장합니다.
5. 앱에서 다시 로그인하면 교사 화면이 열립니다.

다른 선생님은 같은 방법으로 계정 번호를 받아, 필드 `approved`(boolean, `true`)로 문서를 만들어 줍니다. `admin`은 운영자에게만 줍니다. 운영자는 모든 반 기록과 반이 정해지지 않은 기록을 볼 수 있습니다.

## 6. 반과 학생, 태블릿 준비하기

1. 교사 화면에서 **새 반 만들기** → 학생을 **별칭**으로 추가합니다(실명은 쓰지 않습니다).
2. 학생이 쓸 태블릿마다 앱을 열고 선생님으로 로그인해 **이 기기 등록**을 합니다. 한 학생만 쓰면 ‘학생 전용’, 여러 학생이 쓰면 ‘교실 공용’입니다.
3. 등록 뒤 나오는 **이 기기에서 Google 로그아웃**을 눌러 그 태블릿의 Google 계정을 로그아웃합니다. 그대로 두면 학생이 ‘선생님’에서 계정을 고르기만 해도 교사 화면에 들어올 수 있습니다.
4. **닫고 나가기**를 누르고 학생에게 건넵니다.

처음 기록을 불러올 때 ‘색인을 한 번 만들어야 해요’가 보이면, 옆의 **Firebase에서 색인 만들기**를 눌러 만들고 몇 분 뒤 다시 엽니다.

## 7. 태블릿에서 쓰는 주소

학생 태블릿에서 열 주소는 AI Studio의 **공유(Share)** 또는 **게시(Publish)**로 만듭니다. 게시는 Google Cloud Run을 쓰므로 요금이 생길 수 있어, 어떤 방식으로 열지 정한 뒤 진행합니다. 새 주소에서 Google 로그인이 ‘허용되지 않은 주소’라고 나오면 Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 그 주소를 추가합니다.

## 알아 둘 점

- 기록은 내 Google 계정의 ‘AI Studio’ Firebase 프로젝트에 저장됩니다. 무료 공유 한도(하루 읽기 5만, 쓰기 4만 등)를 AI Studio 앱들이 함께 씁니다. 한도를 넘으면 미국 서부 자정(한국 시간 오후 4~5시)이 될 때까지 저장이 멈춥니다.
- 학교 계정이나 별도 프로젝트에 두어야 한다면, 2단계에서 Firebase를 연결할 때 그 프로젝트를 고릅니다(이미 데이터베이스가 있는 프로젝트는 고를 수 없습니다).
- 앱에서는 기록을 지울 수 없습니다. 지워야 할 기록은 Firebase 콘솔에서 운영자가 지웁니다.
- 구글 시트·메일 전송(Apps Script)은 이 판에서 쓰지 않습니다. 기록은 교사 화면과 CSV·성장 보고서로 봅니다.
- 체험판으로 되돌리려면 `app-mode.json`의 `live`를 `demo`로 바꿉니다.
