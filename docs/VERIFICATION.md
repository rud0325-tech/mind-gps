- `npm run lint`: TypeScript 검사 통과.
- `npm test`: 15개 검사 통과. 학습 내용 연결, 상황별 결과와 도움 대안, 나-전달법 문장 조합, 체험 모드의 외부 연결 차단, 입력 검증, 중복 제출, 전송 확인 한계와 시간 제한, 한국 시간 기준 완료 집계 등을 검사했습니다.
- `npm run build`: 배포용 빌드 성공.
- `git diff --check`: 공백 오류 없음.

## 화면 크기

브라우저 화면을 휴대폰 360×800 및 390×844, 태블릿 820×1180, PC 1366×768, 휴대폰 가로 844×390으로 바꾸어 대표 화면을 확인했습니다. 소리 배경의 실제 화면 영역이 PC 화면과 같은 1366×768로 채워진 것도 대조했습니다. 이는 실제 각 기기·브라우저에서의 수업 시험을 대신하지 않습니다.

## 구현했지만 실제 운영 검증은 남은 부분

- Firebase 익명 인증, Google 교사 로그인 및 승인 문서, 배포된 Firestore 규칙과 실제 서버 읽기·쓰기는 접속하지 않았습니다. Firestore Emulator도 실행하지 않았습니다.
- 요청 대기 중 강도 5로 바뀌는 경우의 후속 요청 보존, 서버 확인 전 상태 변경 보류는 코드 검토로 확인했습니다. 실제 서버 지연 상황의 종단 검증은 남아 있습니다.
- 기존 Apps Script 서버 코드와 Gmail 발송 코드는 제공되지 않아 시트 행 생성·메일 수신은 검증하지 않았습니다.
- 브라우저 읽어주기는 선택한 문장에 연결했으나 실제 학생 기기의 한국어 음성 지원·발음·음량은 별도로 확인해야 합니다.
- 학생의 실제 이해도·감정 변화·독립 수행 효과를 측정한 검증은 아닙니다. 선택한 가상 결과를 실제 변화로 기록하지 않습니다.
- 배경 이미지 원본과 음원은 유지했습니다. 일부 이미지와 묶인 JavaScript의 크기가 커 빌드 시 용량 경고가 남습니다. 느린 학교 네트워크에서 최초 로딩 성능을 추가로 확인해야 합니다.
