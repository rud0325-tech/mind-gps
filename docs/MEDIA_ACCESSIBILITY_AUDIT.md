# 음성·영상 접근성 확인 범위 — 2026-10-08

## 이번 작업의 경계

사용자 요청에 따라 **Typecast 녹음·원본 대본이 필요한 작업은 이번 P2에서 제외**합니다. 기존 MP3, MP4, WEBM 및 그림 설명 VTT를 변경하지 않았습니다. 녹음을 새로 만들거나 다른 목소리로 대체하지 않습니다. 자막은 사용자가 켤 때 표시하는 방식이 요청되었으나, 정확한 대본과 시점이 준비되기 전에는 작동하지 않는 자막 버튼이나 추정 자막을 추가하지 않습니다.

KWCAG 5.2.1의 음성·영상 동등 정보, 전체 녹음과 화면 글의 일치 여부는 **사용자 요청으로 보류**합니다. 현재 그림 단계의 문장과 향후 제작용 문장 대본을 기존 전체 안내 녹음의 정확한 대본으로 간주하지 않습니다.

## 이완 영상과 VTT

- 앱의 영상은 `src/assets/relaxation/relaxation-typecast-guide.mp4`입니다. 제작 스크립트·검증 JSON은 기존 `guide_relax.mp3`를 0.875배로 넣고 음높이를 보존했다고 기록합니다. 기존 브라우저 검증 JSON의 디코딩 음성 길이는 41.749초입니다. 이번에는 제작 경로와 메타데이터를 확인했으며 실제 발화를 전사·청취 대조한 것은 아닙니다.
- 네 그림의 전환 시점은 음성 길이를 4등분한 시각적 연습 간격입니다. 말한 문장이나 호흡 길이에 동기화된 값이 아닙니다. 해당 스크립트에는 녹음 대본이 없습니다.
- `public/relaxation-guide.ko.vtt`는 그림의 시각적 설명이며 `kind="descriptions"`로 연결되어 있습니다. 이를 검증된 음성 자막으로 이름만 바꾸지 않습니다.
- 보관 중인 `relaxation-picture-guide.webm`은 이전 무음 영상이며 현재 앱의 재생 소스가 아닙니다.
- 이후 원본 대본·새 음성 자료를 받으면 발화 전체와 의미 있는 소리를 대조하고, 실제 시작·끝 시점에 맞춘 자막을 작성해야 합니다. 영상 속도 0.875와 원본 녹음의 시점을 혼동하지 않아야 합니다. 단순히 문장을 균등 분할한 시간을 자막 시점으로 쓰지 않습니다.

## 이번에 정리한 조작·초점

- 이완훈련에서 단계가 바뀌거나 영상·동작 그림 사이를 이동하면 새 내용으로 초점을 옮깁니다. 문장/단어 화면은 제목, 그림 화면은 숨긴 제목 대신 이름이 연결된 그림 영역에 초점을 둡니다. 처음 화면에 들어올 때의 초점 정책은 앱에 맡깁니다.
- 마음의 소리에서 ‘다른 소리’를 누르면 기존 선택 소리 버튼으로 초점이 돌아갑니다. 소리를 선택하면 재생 제어로 이동합니다. 초점 이동 시 좁은 화면에서 해당 제어가 보이도록 스크롤을 허용합니다.
- 전체화면 진입·해제 때 브라우저가 활동 밖으로 초점을 잃은 경우에만 전체화면 버튼으로 복구합니다. 활동 안의 도움·재생 버튼에 남아 있는 초점은 유지합니다.
- 소리 크기는 기존 네이티브 range와 연결된 ‘소리 크기’ 레이블, 퍼센트 값으로 조작합니다. 별도의 복잡한 입력 방식을 추가하지 않습니다.
- P1의 도움 버튼 위치·순서·안내 및 P0의 데이터 처리 방식은 유지합니다.

## 남은 실행 확인

루트 작업에서 키보드 단계 이동, 영상 열기/그림 복귀, 다른 소리 선택, 전체화면 진입·Esc 해제, 음량 조절을 확인합니다. 실제 VoiceOver/TalkBack, 스위치, 학교의 각 기기에서 전 과정 사용 가능성은 별도 시험입니다. 코드의 초점 관리만으로 모든 보조기술 사용 가능성을 인증하지 않습니다.

로컬 자동 전사 가능성만 확인했으며 음성을 인식기에 전달하지 않았습니다. 설치된 전사 도구가 없고 macOS 한국어 온디바이스 인식도 지원되지 않았습니다. 음성 인식 권한 요청·마이크 사용·외부 전사 서비스·AI API 호출은 하지 않았습니다.
