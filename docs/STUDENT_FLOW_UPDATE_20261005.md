# MindGPS 생각바꾸기·선택 화면 수정본

2026-10-05. 실제 저장·메일 연결은 앱이 어느 정도 완성된 뒤 진행한다는 사용자 결정을 유지합니다. 저장 방향은 Firebase 원본 + Google Apps Script/구글 시트 정리 + 부정 감정 5단계/도움 요청 시 교사 이메일 알림이며, 이번에는 운영 설정을 변경하지 않았습니다.

## 반영한 내용

1. 생각바꾸기: 알아보기를 이미 마친 뒤에도 구름 게임으로 전환하면 누를 수 있는 생각 구름부터 시작합니다. 구름을 누르고 다른 가능성을 살펴본 다음 도움 되는 생각을 고릅니다.
2. 그림 수준: 기본 10가지 상황과 각각의 생각·도움 선택을 구체적인 인물 동작과 물건이 보이는 장면으로 구성했습니다. 상황 그림을 한 페이지에 두 장씩 크게 비교합니다. 학생이 그림을 누르면 해당 문장을 듣고 선택합니다. 직접 등록한 내용은 임의로 추측하지 않는 중립 그림을 유지합니다.
3. 생각바꾸기 음성: 문장별 타입캐스트 MP3가 아직 없으므로 기기 기본 음성으로 정확한 선택 문장만 임시 재생합니다. 이후 지정된 MP3를 넣고 다시 빌드하면 그 문장의 타입캐스트 녹음이 우선합니다. 현재 기기 음성이 타입캐스트와 같은 목소리라는 뜻은 아닙니다.
4. 나전달법: 마지막 버튼을 ‘표현했어요’로 바꿨습니다. 말하기·그림 가리키기·문장 보여주기 모두 포함합니다.
5. 기다리기 부탁은 ‘얼마나 더 기다려야 하는지 알려 주세요.’와 ‘기다리는 동안 잠깐 쉴래요.’입니다. 특정 취미를 전제하지 않도록 그림 그리기는 제외했습니다. 단어는 ‘기다릴 시간’·‘잠깐 쉬기’이며, 쉬기 그림에는 빈백에서 쉬는 학생과 시계가 나옵니다.
6. 활동 선택 화면의 생각바꾸기·마음의 소리 이름에서 괄호와 영어를 뺐습니다.
7. 감정·강도 선택: ‘다음’을 크게 하고 보조 버튼은 작은 ‘지금은 건너뛸래요’ 한 개만 제공합니다. 전후 화면에 동일하게 적용하며, 응답을 강요하거나 미응답을 0점으로 바꾸지 않습니다. 통합 버튼의 미응답 사유는 건너뛰기로 기록합니다.
8. 오늘의 한마디: 바꾼 생각을 보고 듣고 표현하는 단계로 정리했습니다. 이 단계의 칭찬·카드 이미지 저장을 제거했습니다. 바꾼 생각 정리 → 활동 후 감정 → 칭찬·파워카드 저장 순서입니다.
9. 나전달법 친구 상황은 ‘친구가 나를 놀리는 말을 해요.’입니다. 부탁은 ‘그런 말은 하지 말아 줘.’·‘나한테 다정하게 말해 줘.’이며, 완성 문장도 ‘네가 나를 놀리는 말을 하면 나는 속상해. 그런 말은 하지 말아 줘.’처럼 반말로 구성합니다. 안내와 질문의 존댓말은 유지합니다.
10. 학습 상황은 ‘지금 하는 활동이 어려워요.’입니다. 부탁은 ‘한 번 더 알려 주세요.’·‘조금 더 쉬운 걸로 해 볼래요.’로 수정했습니다. 같은 활동의 설명을 다시 듣거나 난이도를 낮춰 참여하도록 요청하는 선택입니다. 그림도 다시 설명하는 장면과 여러 모양에서 한 모양으로 간단해진 과제로 맞췄습니다.
11. 마음의 소리: 입장과 소리 다시 선택 화면의 기본 빗사진을 크림색·옅은 세이지·하늘색의 정적 배경으로 바꿨습니다. 제목·설명은 어두운 글자로 표시하며, 소리를 선택한 뒤에는 해당 소리의 사진을 전체 배경으로 보여 줍니다.
12. 나전달법 완성 문장: ‘1 상황 / 2 내 마음 / 3 부탁’을 표시한 세 칸으로 구분했습니다. 글 수준과 ‘문장으로 보기’에 동일하게 적용하며, 음성은 세 칸의 실제 문장을 이어서 읽습니다. 문장 내용과 v5 음성 대본은 그대로입니다.

## 확인

이전 검토에서 구름 게임 전환, 그림 선택, 바뀐 생각 정리 → 활동 후 감정 → 칭찬·다운로드 순서를 확인했습니다. 휴대폰 360×640, 태블릿 가로 1024×768, 낮은 가로 812×375에서 배치를 점검했습니다. 이번 친구·학습 상황 변경은 전체 테스트 70개로 문장 구성, 친구 말투, 음성 파일 연결을 확인했습니다. 실제 학생이 그림을 이해하는 정도와 실제 수업 기기의 음성 품질은 수업 적용 후 검토할 부분입니다.

친구 상황 변경 당시 타입 검사와 빌드를 통과했습니다. 브라우저에서 친구 상황·반말 부탁·반말 완성 문장과 ‘표현했어요’ 다음 활동 후 감정 기록을 확인했습니다. 당시 학습 상황은 그림 수준에서 완성 문장을 확인했으며, 360×640 화면에도 두 부탁과 다음 버튼이 함께 표시되었습니다. 이후 학습 부탁 두 개를 다시 설명·더 쉬운 활동으로 변경하고, 문장 구성과 이전 음성 연결 방지 검사 13개를 통과했습니다.

v5의 타입 검사와 빌드도 통과했습니다. 브라우저에서 새 부탁 두 개의 그림·문장과 각각의 완성 문장 연결을 확인했습니다.

완성 문장 구분·소리 배경 변경 후 문장 및 음성 연결 검사 13개, 타입 검사, 빌드를 통과했습니다. 브라우저에서 360×640과 812×375 크기의 완성 문장 세 칸과 완료 버튼이 스크롤 없이 표시됨을 확인했습니다. 마음의 소리 선택 화면도 360×640에서 넘침이 없고 전체 배경 사진이 없음을 확인했으며, 파도 소리 재생·멈춤·다시 선택의 상태 전환을 점검했습니다.
